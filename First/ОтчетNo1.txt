Отчёт по этапу 1:

Обработка запроса происходит по следующему сценарию:
1.	Клиент отправляет HTTP запрос на порт 8080.

2.	http.ListenAndServe принимает соединение, парсит запрос, создаёт *http.Request.

3.	http.ServeMux сопоставляет путь запроса с зарегистрированным обработчиком.

4.	Вызывается соответствующая функция обработчик с http.ResponseWriter и *http.Request.

5.	В обработчике проверяется метод (для /ping), устанавливается статус код, записывается header.(через curl можно проверить статус-код)

6.	Сервер отправляет HTTP ответ (статус, заголовки, тело) клиенту, закрывает соединение.

Проверить работу через браузер можно по ссылкам:
	http://localhost:8080/ → отображается приветствие;
	http://localhost:8080/about → отображается описание проекта;
	http://localhost:8080/ping → отображается «pong».
Проверить статус код /ping можно введя в командную строку: 
	curl http://localhost:8080/ping
